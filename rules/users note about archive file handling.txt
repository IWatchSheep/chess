"
Here's the reworded version as a spec for both AIs. I added a small structure sketch at the end so the nesting of archive, chunk, memory and bank is clear.

---

**Goal: archives that teach Lists 1 and 3 the whole game**

**Purpose.** The archives of old files exist for one reason: to help **List 1** and **List 3** make better guesses when they form **Strategy 1** and **Strategy 3**.

**The problem.** Right now each old file keeps only:
- 4 past moves
- 1 present move
- 1 future move

Everything else is deleted. When the game ends, the only thing left is the end of the game. The start and middle are lost, so Lists 1 and 3 can't learn how to plan a whole game.

**Rule 1: one archive = one full game**
- An archive file holds **every move of the entire game, for both sides**.
- Each move is stored as a chunk:
  `[4 past turns] + [current turn] + [1 future turn]`
- Past links to present, and present links to future, so the AI can see what led to each move and what followed it.
- The chunks are kept in game order from first move to last, so the AI can read any part of the game.
- **Every turn in a chunk shows all the pieces on the board**, not just the piece that moved.

**Rule 2: Memory**
- Every archive goes into a list called **"memory"**.
- "memory" is sorted so the **most useful archives are at the front**.
- "memory" is capped at a set number of archives. Anything past the cap is dropped.
- A sorted "memory" is how the AI learns.

**Rule 3: Banks**
- **"banks"** is a list that holds one **sorted "memory"** list per task.
  - Example: a bank for the Claude grid board, which holds the archives of solved grid boards.
- When List 1 or List 3 forms a strategy, it reads the bank for the current task. Each memory in that bank helps it pinpoint a more accurate strategy.

**Structure sketch**
```
banks = {
  "claude_grid_board": memory,   # one sorted memory per task
  "other_task":        memory,
}

memory = [archive, archive, ...]   # most useful first, max N

archive = {                        # one full game, both sides
  game_id,
  chunks: [chunk_1, chunk_2, ...]  # one per turn, in game order
}

chunk = {
  past:    [turn-4, turn-3, turn-2, turn-1],
  present: turn,
  future:  turn+1
}

turn = { player, move, all_piece_positions }
```

**Context:** the YouTube video "The_Two_Things_AI_Will_Never_Do" discusses the limitations of AI. This archive and memory design is meant to work around one of them, which is that the AI forgets what came earlier.

---

Two values are still undecided: how "useful" is scored and how big N is. If you don't set them, each AI will pick its own. Also, I wrote the last line of Context as my reading of why you mentioned the video. Change it if that's not your point.
